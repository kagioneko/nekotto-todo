# ねこっと ToDo 🐾

手書き風の癒やし系タスク管理アプリです。
タスクの期限や状態に合わせて、猫のイラストが変化します。

## 起動方法（開発モード）

以下のコマンドで開発サーバーを起動し、デスクトップアプリとして開きます。

```bash
npm run electron:dev
```

## 配布用ファイルの作成（ビルド）

以下のコマンドでWindows用のアプリファイルを生成できます。

```bash
npm run electron:build
```

### 生成物の場所
ビルドが成功（または一部成功）すると、以下のフォルダにアプリが生成されます。

- **`release_new/win-unpacked`**: すぐに実行可能なフォルダ形式のアプリ
    - この中の `Nekotto ToDo.exe` をダブルクリックすると起動します。
    - 他の人に渡す場合は、この `win-unpacked` フォルダごとZip圧縮して渡してください。
- **`release_new`**: インストーラー（`.exe`）
    - ※環境によってはインストーラー作成時にエラーが出ることがありますが、その場合でも上記の `win-unpacked` が出来ていれば問題なく使用できます。

## 機能
- **猫の状態変化**: 😺通常 / 😳期限間近 / 🫠完了 / 📝放置
- **データ保存**: アプリを閉じてもタスクは残ります

## 技術スタック
React, Vite, Electron
